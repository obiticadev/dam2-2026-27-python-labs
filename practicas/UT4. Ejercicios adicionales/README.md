# UT4. Ejercicios adicionales

Plantillas sin resolver, siguiendo la numeración y los cinco bloques del aula.
Los enunciados completos, niveles, restricciones y datos de ejemplo están
incluidos como docstrings en los archivos Python.

- Bloques 1–4: un archivo `ejercicio_NN_descripcion.py` por ejercicio.
- Bloque 5: una carpeta `ejercicio_NN_descripcion/` por ejercicio, con un módulo
  para las funciones y `principal.py` para las pruebas y el programa principal.
  Esta separación es organizativa; no añade requisitos al enunciado original.
- Todos los `.py` contienen solo documentación: no hay funciones resueltas,
  código de solución ni salidas extraídas de las soluciones.
- No se necesitan dependencias externas ni un entorno virtual por ejercicio.

[Recurso original del aula](https://aulavirtual3.educa.madrid.org/ies.alonsodeavellan.alcala/pluginfile.php/295080/mod_resource/content/1/UT4-Ejercicios_adicionales.html) (requiere iniciar sesión).
El HTML original se conserva fuera del repositorio; aquí no se incluyen sus soluciones.

## Introducción del cuaderno

Este cuaderno recoge 50 ejercicios para practicar los contenidos de la UT4, organizados en cinco bloques de diez ejercicios cada uno: cadenas (ejercicios 1-10), listas (11-20), tuplas (21-30), diccionarios (31-40) y problemas integrados (41-50) que combinan varias estructuras.

Dentro de cada bloque los ejercicios están ordenados de menor a mayor dificultad y se clasifican en tres niveles:

- Básico: una o dos operaciones sobre la estructura, con una función corta y pocos casos de prueba.

- Medio: varias operaciones combinadas, funciones que se apoyan unas en otras y tratamiento de casos límite sencillos (colección vacía, clave inexistente).

- Alto: problemas que exigen diseñar un algoritmo o combinar estructuras anidadas (bucles dentro de bucles, listas de diccionarios, diccionarios de listas, tuplas dentro de tuplas...). Cada bloque incluye tres ejercicios de este nivel.

Todos los ejercicios utilizan únicamente elementos trabajados hasta esta unidad (variables, condicionales, bucles, funciones, módulos y las estructuras de datos de esta unidad).
