# UT3. Ejercicios adicionales

Los ejercicios están preparados como plantillas sin resolver:

- El bloque 1 contiene un archivo Python independiente por ejercicio.
- El bloque 2 contiene un proyecto por ejercicio, formado por el módulo solicitado y `principal.py`.
- El bloque 3 contiene un proyecto independiente por ejercicio, con un archivo `principal.py`.

Los enunciados están incluidos como docstrings dentro de los archivos para poder consultarlos desde el IDE.
